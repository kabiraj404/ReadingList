I tried to fork and use it, but I was not able to do it, so I created my own style of doing it. <br>
My approach is simple: I use a browser bookmarklet to save webpage information into a json file stored in my repository. The bookmarklet grabs the page title, url, site name, author, and today's date. It then prompts for a personal tag where I can add my thoughts or impressions about the article, and uses the github api to fetch the existing list and commit the updates back to the file. There are four steps, each with an alert so I know which step is causing a problem.
